# Introduction

`imgdisp` is a set of classes for reading and searching star catalogs. Currently NAIF SPICE
star catalogs, the Yale Bright Star Catalog (YBSC), and UCAC4 are supported.

`imgdisp` is a product of the [PDS Ring-Moon Systems Node](https://pds-rings.seti.org).

# Installation

The `imgdisp` module is available via the `rms-imgdisp` package on PyPI and can be installed with:

```sh
pip install rms-imgdisp
```

# Getting Started
